jQuery Selectors Used

ButtonClick
Selects the button using its ID. The click event changes its text.
Double Click
Selects the paragraph using its ID. The double-click event toggles a CSS class.
Hover Image
Selects the image using its ID. The hover event hides the image with a fade effect.
Document Ready
Ensures the jQuery code runs only after the page has fully loaded.
